This is a simple web application I made during a web development tutorial at my university. It allows you to look up the live weather for cities around the world. Live weather data is fetched from OpenWeatherMap's free API (https://openweathermap.org/api).

The city's temperature displayed on the webpage will be updated based on the provided weather data. Notice that the weather condition (cloudy, rainy, sunny, etc.) will also be updated with a corresponding pictogram.

This was my first time learning about front-end development with React.js (and JavaScript) and creating a dynamic website, and it has inspired me to build other, cooler web applications.

Check out the web app here: https://kinsonchk.github.io/Dynamic-Weather-App/
